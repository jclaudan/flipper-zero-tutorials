Attached are sample JavaScript files (train1.js, badusb_demo.js, blebeacon.js, disk.js, event_loop.js, gui.js, i2c-spi.js, interactive.js, spi.js, subghz.js, flipper_http_example.js) that work on the Flipper Zero. Flipper Zero JavaScript is based on the mJS engine, which is fairly restricted version of JavaScript.  You should only use functions defined in the training file, no additional built-in commands are supported.  You should not redefine any function that is used in the training file. Please see the comments in train1.js file for more details.

NEW CAPABILITY: HTTP and WiFi Support via FlipperHTTP
The flipper_http_example.js file demonstrates how to use the FlipperHTTP module for:
- HTTP GET, POST, PUT, DELETE requests with custom headers
- WiFi connection management (connect, disconnect, scan, save credentials)
- JSON data parsing from API responses
- WebSocket connections for real-time communication
- IP address retrieval for both WiFi and board
- LED control during processing

This requires the FlipperHTTP firmware to be flashed on the Flipper Zero. See flipper_http_docs.txt for complete API documentation.
